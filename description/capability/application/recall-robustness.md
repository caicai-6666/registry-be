# 相似文件召回鲁棒性实验

> **用途：** 用真实合同 PDF 检查摘要表达变化对候选召回的影响，区分相似度阈值、候选数量与 HNSW 近似检索造成的漏检。不将相似度直接解释为重复概率。

---

## 实验范围与依赖

实验使用指定目录中的全部可读 PDF，原件只读，按文件字节 SHA-256 合并完全相同的副本。用现有 PDF 服务逐页渲染，再通过已配置的多模态模型生成摘要；没有文本层的扫描件也参与实验。

模型生成摘要是实验代理数据，不能代表尚未收集的子平台真实 `abstract`。摘要事实和改写质量未经全量人工标注；“不同 PDF”也不自动等于“不重复”。本实验不能给出正式判重准确率或误拒率。

依赖现有 vLLM、多模态客户端、LlamaIndex embedding 和 MyVector；精确基准使用 NumPy。可视化使用实验环境中的 Matplotlib，不加入后端运行依赖。

---

## 受控正例与压力场景

每份文件的原始摘要进入固定检索库，查询由同一文件摘要构造。已知目标是对应原始文件，而不是未经标注的其他邻近合同。

| 场景 | 构造 | 用途 |
| --- | --- | --- |
| 完全相同或改名控制 | 摘要字节不变，文件名不进入模型 | 基础控制；不能证明内容识别鲁棒性。 |
| 语义改写 | 同一 PDF 生成另一种摘要表达 | 检查措辞差异。 |
| 短摘要 | 压缩主体、标的及交易信息 | 检查信息压缩。 |
| 句序变化 | 反转摘要句序 | 检查表述顺序。 |
| 字符删除 3% / 10% | 按文件哈希固定随机种子删字符 | 可重复的噪声压力测试，不声称等同真实 OCR 分布。 |
| 通用条款干扰 | 摘要前添加重复通用合同条款 | 检查无关或低区分信息干扰。 |
| 仅通用描述 | 所有文件使用相同泛化短描述 | 信息不足的极端场景；单列结果，不混入常规召回率。 |

所有查询保留来源、类别和扰动种类；扫描或稀疏文本文件与可提取文本文件可分别统计。按文件哈希固定分为标定组和验证组，同一文件的所有变体属于同一组；验证组的目标仍在检索库中，这是查询变体的独立评估，不是“库中不存在目标”的测试。

全量运行另在冻结的短摘要上保留前 80、40、20 字，逐级删除信息，单独保存于 `compression-stress/`。这是可重复的前缀截断实验，不代表相同字数的自然摘要都具有相同表现。另对 16 份摘要比较单条和批量 embedding 输出，记录数值一致程度。

## 指标与判断边界

精确余弦基准先对全库排序，再按阈值和 `TOP_K` 判断目标是否进入候选。分别统计仅阈值失败、仅排名失败和二者均失败；降低阈值不能修复排名超过候选上限的情况。

网格包含阈值 `-1`（无实质相似度门槛）、`0.5` 至 `0.95`，以及候选数量 `1`、`3`、`5`、`10`、`20`。HNSW 在独立临时 MySQL 容器中运行，使用与业务相同的 MyVector 适配器和平台过滤，结束删除容器及其临时卷，不写正式资源或索引表。

HNSW 的近邻预算随 `TOP_K` 变化：当前适配器 Top5 请求至少 100 个 ANN 候选，Top20 请求至少 200 个。因此不能只请求 Top20 再截取前五，便声称验证了实际 Top5 行为。首轮运行保留 Top20 对照，另用 `scripts/recall_robustness_hnsw.py --run <运行目录>` 在冻结向量上补测真实 Top5；新版主运行器默认直接请求 Top5，可通过 `--hnsw-top-k 20` 切换对照。

不同文件的高分邻近对仅用于筛选需人工复核的混淆样本。除字节完全重复外，不能自动给它们贴负例标签，更不能把高分数量直接视为误判数量。

## 运行与产物

```bash
conda activate registry-be
python scripts/recall_robustness.py \
  --source '/绝对路径/合同PDF目录' \
  --output experiment/recall-robustness/<唯一运行标识> \
  --concurrency 4
```

`--limit` 用于小规模试跑，`--skip-hnsw` 用于只验证模型与精确基准。首次运行保存源文件清单、模型参数、提示词及运行器副本；摘要原始响应逐次留存，嵌入向量按文本哈希缓存。同一运行目录可恢复未完成工作，但完成后不覆写既有原始产物。

产物包括 `inventory.json`、`manifest.json`、`raw-chat/`、`summaries/`、`queries.json`、`embedding-cache/`、`vectors.npz`、`exact-results.json`、`metrics.json`、`cross-document-pairs.json`、HNSW 结果和清理记录。人工分析在该次运行的 `analysis.md` 追加，不能把结论写回原始响应。

实验提示词及历史导航仅在另备本地产物的环境可用，分别为 `experiment/recall-robustness/prompts.md`、`experiment/readme.md`；脚本、样本和原始响应不随 Git 交付。目录边界见[测试与实验规范](../../standard/experiment.md)。
