# 向量化指令探索实验

> **本地产物边界：** 下述 `scripts/`、`experiment/` 脚本与实验报告不纳入 Git，链接用于定位原开发环境的证据；新克隆需另行取得对应工具和冻结样本才能复现实验。正式部署不依赖这些产物。


实验比较摘要原文、默认语义表示指令和面向判重/关联检索的任务指令，用于决定 embedding 输入格式和后续向量契约。正式生成入口仍是 [EmbeddingService](../../../app/service/embedding.py)，本实验不修改该服务或现有业务向量。

---

## 执行方式

```bash
python scripts/embedding_instruction_trial.py --output experiment/embedding-instructions/<新运行目录>
```

复用 `experiment/recall-robustness/20261013-full/` 中冻结的 179 份合同摘要与变体，读取现有 embedding 环境配置；输出只允许位于 `experiment`。输出目录已有 manifest 时拒绝覆盖。运行依赖项目现有 httpx、NumPy，无新增包。

校准集按来源 PDF、文本提取类别固定抽样，validation 保持原实验划分；同一 PDF 的摘要变体不跨分组。默认每批 16、并发 3，实际调用远端服务，使用有界重试。只读取本地样本，不访问业务数据库或消息流。

---

## 比较方式

- 原文基线通过 `/v1/embeddings` 的 input 发送，与现有正式服务一致。
- 指令通过 messages 的 system 发送，摘要位于 user；使用服务支持的批量消息协议，不假定手工拼模板字符串与聊天输入等价。
- 默认文档向量与任务查询向量分开比较，区分模板带来的效果与任务指令本身的效果。正式实现当前只保存一份摘要向量，因此实验结论不自动意味着可以直接替换配置。
- 校准阶段比较默认、通用相关性、英文/中文判重、强关联和兼顾具体事实的指令；具体文本保存在运行目录 instructions.json。
- 用精确余弦排序衡量 Recall@1/5、MRR 和已有 0.8 阈值下的召回，按源文件聚类计算配对 bootstrap 区间；不将 HNSW 近似误差混入指令比较。
- 单独构造主题相关性合成集，计算 Recall@3 和 nDCG@5；合成主题不是实际通行证，不报告为线上推荐准确率。

全部候选与选优规则在 validation 前固定，选择结果保存后不再按 validation 调整指令。相同摘要控制组、泛化摘要信息不足压力组单列，不参与选优。

## 产物与限制

每次运行保存 manifest、冻结数据、指令、运行器快照、压缩原始请求响应、归一化向量、逐查询排名、选优结果和指标；凭据、认证头和服务地址不写入产物。人工分析追加到 analysis.md，与原始产物分离，规则见[实验规范](../../standard/experiment.md)。

已知正例仅表示同一来源 PDF 的摘要扰动；不同 PDF 之间可能仍然重复，不能全部当负例。179 份文件来自合同领域，不代表全部子平台；少量已核对难例不构成完整误拒率评估。系统指令会改变向量空间和分数分布，不能把旧阈值或旧向量直接视为兼容。

官方模型说明与示例：[Qwen3-VL-Embedding](https://github.com/QwenLM/Qwen3-VL-Embedding)、[vLLM 示例](https://github.com/QwenLM/Qwen3-VL-Embedding/blob/main/examples/embedding_vllm.ipynb)。实际服务协议与上游模板差异由运行目录中的探针留证。


## 本次结果

[2026-10-21 运行分析](../../../experiment/embedding-instructions/20261021-193654/analysis.md)比较 179 份真实合同候选，使用独立 81 份源文件、486 条非控制变体验证。当前原文 Recall@5 为 100%，较好的任务指令对称 generation=true 为 99.38%；沿用 0.8 后为 94.65%。本次未找到支持替换正式方式的证据，真实通行证推荐质量仍缺少标注验证。具体置信区间、格式差异及限制以报告为准。

## 面向双用途的通用业务指令

进一步探索使用 `scripts/generic_embedding_trial.py`，目标是同一份向量同时支持内容重复召回和具体业务事项的直接关联召回。候选从“执行检索”改为“表示文件”，比较简短业务语义、实体事实和配套关系的中英文表达。全部指令方案固定对称 messages + generation prompt，不再把输入格式与提示词内容一起改变。

```bash
python scripts/generic_embedding_trial.py --output experiment/embedding-instructions/<新的业务实验目录>
```

校准沿用 32 份源文件；确认使用先前指令比较未用于选优的另外 66 份。除真实摘要变体外，加入明确引用真实合同短摘要的假设验收/结算材料，以及同主体同标的但不同事项的受控合成对照。合成和假设材料均独立标识，不冒充实际审核记录或通行证标签。

以同内容 Recall@5、假设配套材料 Recall@5、受控关联 nDCG@5 的调和平均排序，先固定前两条通用候选再做确认；单独检查同内容召回相对原文的退化。该评分是本轮明确设定的业务权衡，不是通用的行业最优标准。其他数据、产物和隔离边界沿用上述约定。

## 中性指令与官方中英文对照

用户进一步明确指令只应描述“为摘要生成相似查找向量”，不在模型指令中加入合同、判重、通行证或具体业务关系。业务用途用于评价，不作为指令内容。前述业务语义方向已中断留档，不能把其部分校准结果视为最终结论。

```bash
python scripts/neutral_embedding_trial.py --output experiment/embedding-instructions/<新的中性指令目录>
```

成对比较官方默认英文及中文译文、官方检索示例英文及中文译文、面向摘要相似检索的中英文中性表达；中文译文明示为本实验翻译，不冒称官方发布。保留原文基线，固定对称 messages + generation prompt，六条指令在同一确认集全部评价，语言差异按相同任务成对报告。

本轮具体指令和选择规则见运行目录 protocol.md、instructions.json；不使用面向其他模型的输入前缀替代 Qwen3-VL 的指令接口。假设及受控样本仍不代表真实通行证标签，不能把样本内排序宣称为所有子平台的全局最优。


### 最新中性指令结果

[官方及中英文对照分析](../../../experiment/embedding-instructions/neutral-20261021-195724/analysis.md)记录六条中性指令的完整确认。校准和确认均较均衡的带指令候选为“检索与用户查询相关的图像或文本。”，它是官方英文检索示例的本轮中文译文，不是官方发布的中文指令。

在 66 份源文件、396 条同源变体上，该候选 Recall@5 为 99.24%；明确引用合同摘要的 132 条假设配套材料为 100%。原文参照两者均为 100%，因此没有证明新指令整体优于原文。它在研发/质量/培训/制度执行的少量受控样本中表现良好，但不能代替真实非合同平台的标注。

语言应按同一任务成对比较：本轮不能概括为中文始终优于英文。指令输入格式、阈值变化、区间、原始请求和独立重算证据均见报告。本轮未更改正式配置或向量。

## 用户最终确定与正式接入

后续用户明确只对文本摘要检索，最终确定“检索与这份摘要语义相关的文本。”，现已接入正式 EmbeddingService 的单条、批量及查询入口。旧实验推荐的中文译文包含“图像或文本”，不能将其历史指标直接视为最终表述的实验成绩。

正式输入、响应校验、并发/重试和旧向量兼容处理见[MyVector 与固定摘要指令](../infrastructure/myvector.md#固定摘要相似检索指令)。本次代码接入不重跑历史实验、不改写其原始产物，也不自动调整业务阈值。
